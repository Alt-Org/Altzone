Detailed Description

Abstract base shield class view controller Unity MonoBehaviour script🡵.
Abstract base class for the shield class view controllers to extend.

Defines shield class view controller structure, implements base non-specific view logic for all shield classes. Provides hooks for derived classes to implement shield class specific view logic. Works together with BattlePlayerShieldViewController, which handles the shared player shield view logic.

See {PlayerShieldClassViewControllers} for more info.
See {Player Character Classes} for more info.

Called by the BattlePlayerShieldViewController OnViewInit (OnActivate).
Initializes this instance of a shield class view controller. Performs base non-specific initialization for all shield classes.
Stores references to the parent controller and entity, then calls the protected OnViewInitOverride method that performs the shield class specific initialization.

This is not an overridable method. Override the OnViewInitOverride method in derived classes for implementing shield class specific custom initialization.
