View Registry

The BattleViewRegistry handles mapping Quantum entities to any Objects related to the entities.
The point of this class is to link Quantum entities to each other on the view side of Quantum.
Objects are mapped to a given Quantum entity using Register.
Objects are retrieved using GetObject<T> or GetObjects<T> depending on if multiple objects need to be retrieved or not.
If an Object needs another Object related to a different Quantum entity to function and it isnt known if the object has been registered to this system yet or not, the WhenRegistered method needs to be used.
