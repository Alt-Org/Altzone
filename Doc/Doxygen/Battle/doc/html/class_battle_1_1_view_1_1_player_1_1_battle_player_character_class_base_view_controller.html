Detailed Description

Abstract base character class view controller Unity MonoBehaviour script🡵.
Abstract base class for the character class view controllers to extend.

Defines character class view controller structure, implements base non-specific view logic for all character classes. Provides hooks for derived classes to implement character class specific view logic. Works together with BattlePlayerCharacterViewController, which handles the shared player character view logic.

See {PlayerCharacterClassViewControllers} for more info.
See {Player Character Classes} for more info.

Called by the BattlePlayerCharacterViewController OnViewInit (OnActivate).
Initializes this instance of a character class view controller. Performs base non-specific initialization for all characters classes.
Stores references to the parent controller and entity, then calls the protected OnViewInitOverride method that performs the character class specific initialization.

This is not an overridable method. Override the OnViewInitOverride method in derived classes for implementing character class specific custom initialization.

Parameters
