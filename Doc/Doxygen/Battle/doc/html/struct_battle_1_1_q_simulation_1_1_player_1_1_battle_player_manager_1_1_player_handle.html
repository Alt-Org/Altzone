Detailed Description

Public helper struct for getting player information.

Has static helper methods for retrieving player information.
Can be instantiated to retrieve a specific player's information.

See {PlayerHandle} for more info.
See {Player Overview} for more info.
See {Player Simulation Code Overview} for more info.

This is a public wrapper for the private PlayerHandleInternal that is used by the BattlePlayerManager internally.
This only exposes the parts of the PlayerHandleInternal that is meant to be accessible outside of BattlePlayerManager.
