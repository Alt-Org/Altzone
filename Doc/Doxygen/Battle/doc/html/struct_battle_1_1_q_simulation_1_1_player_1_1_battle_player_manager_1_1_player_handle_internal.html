Detailed Description

Internal helper struct for player information, operations and state management in BattlePlayerManager.

Has static helper methods for player operations.
Can be instantiated to handle a specific player's data stored in BattlePlayerManagerDataQSingleton.

See {PlayerHandle} for more info.
See {Player Overview} for more info.
See {Player Simulation Code Overview} for more info.

The public PlayerHandle wrapper is used by code outside of BattlePlayerManager.
