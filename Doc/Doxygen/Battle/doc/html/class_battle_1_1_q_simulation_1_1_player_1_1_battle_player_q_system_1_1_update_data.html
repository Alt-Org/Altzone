Detailed Description

Class containing all necessary data for player Update logic.

Created at the start of the Update method.

The data is split into 3 categories:

  • Common Data
    Common data related to the update logic.
  • Current Player Properties
    Data related to the current player that is being processed.
    Is set for each player that is being processed using SetPlayer.
  • Current Player Character Properties
    Data related to the current player character that is being processed.
    Is loaded for each player character that is being processed using LoadPlayerCharacter.
