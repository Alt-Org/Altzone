Detailed Description

Joystick UI Component (Unity MonoBehaviour script🡵).
Handles Battle Ui joystick drag input functionality using IPointerDownHandler, IDragHandler and IPointerUpHandler interfaces.

This script is meant to be attached to BattleUiJoystick prefab's top level GameObject, since it calculates _joystickRadius from the same GameObject🡵's RectTransform🡵 component.
