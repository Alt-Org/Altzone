Detailed Description

Contains all battle events.

Events

Game Flow events - View Pre-Activate

  • synced event BattleViewWaitForPlayers {}
    Synced event. Used when waiting for for all players to get registered.
  • synced event BattleViewPlayerConnected {}
    Synced event. Used when a player connects to the game.
  • synced event BattleViewAllPlayersConnected {}
    Synced event. Used when all players have connected to the game.
  • synced event BattleViewInit {}
    Synced event. Used for initialization after players are ready.

Game Flow events

  • synced event BattleViewActivate {}
    Synced event. Used to activate view after initialization is ready.
  • synced event BattleViewGetReadyToPlay {}
    Synced event. Used when the start countdown is finished.
  • synced event BattleViewGameStart {}
    Synced event. Used when the game starts.
  • synced event BattleViewGameOver { BattleTeamNumber WinningTeam; FP GameLengthSec }
    Synced event. Used when the game ends.

ViewInit events

  • synced event BattlePlayerCharacterViewInit { EntityRef ERef; BattlePlayerSlot Slot; BattlePlayerCharacterID CharacterID; BattlePlayerCharacterClass CharacterClass; int ShieldCount; FP ModelScale }
    Synced event. Used to initiate player character's view model on Unity side.
  • synced event BattlePlayerShieldViewInit { EntityRef ERef; EntityRef CharacterRef; BattlePlayerSlot Slot; BattlePlayerCharacterID CharacterId; BattlePlayerCharacterClass CharacterClass; int ShieldNumber; FP ModelScale }
    Synced event. Used to initiate player shield's view model on Unity side.
  • synced event BattleSoulWallViewInit { EntityRef ERef; FP ModelScale; int EmotionIndicatorColorIndex; int DebugColorIndex }
    Synced event. Used to initiate SoulWalls's view models on Unity side.
  • synced event BattleStoneCharacterPieceViewInit { int WallNumber; BattleTeamNumber Team; int EmotionIndicatorColorIndex }
    Synced event. Used to set EmotionIndicatorColor for StoneCharacterPieces.

UI control events

  • synced event BattleViewSetRotationJoystickVisibility {bool IsVisible, BattlePlayerSlot Slot }
    Synced event. Used to set the rotation joystick UI element to be shown or hidden.

Gameplay events

  • synced event BattleChangeEmotionState { BattleEmotionState Emotion }
    Synced event. Used to change sprites etc. during game depending on given BattleEmotionState.
  • synced event BattleProjectileChangeSpeed { FP NewSpeed }
    Synced event. Used to update the projectile's trail based on it's speed.
  • synced event BattleProjectileChangeGlowStrength { FP Strength }
    Synced event. Used to change glow strength during game depending on the projectile's attack damage.
  • event BattlePlaySoundFxForAll { BattleSoundFX Effect }
    Non-synced Event. Used to play sound effects during battle for everyone.
  • event BattlePlaySoundFxForTeam { BattleTeamNumber Team; BattleSoundFX Effect }
    Non-synced Event. Used to play sound effects during battle for a player's team.
  • event BattlePlaySoundFxForPlayer { BattlePlayerSlot Slot; BattleSoundFX Effect }
    Non-synced Event. Used to play sound effects during battle for a player.
  • synced event BattleLastRowWallDestroyed { BattleTeamNumber Team; int WallNumber }
    Synced event. Used when a last row SoulWall segment is destroyed.
  • synced event BattleDiamondLanded { EntityRef ERef }
    Synced event. Used when a diamond stops traveling across the arena.
  • synced event BattleCharacterSelected { BattlePlayerSlot Slot; int CharacterNumber }
    Synced event. Used when a player character is spawned or despawned.
  • synced event BattleCharacterHit { EntityRef ERef; BattleTeamNumber Team; BattlePlayerSlot Slot; int CharacterNumber; int ShieldNumber; FP StunDurationSec; BattleEmotionState ProjectileEmotion }
    Synced event. Used when a character gets hit.
  • synced event BattleShieldHit { EntityRef ERef; BattleTeamNumber Team; BattlePlayerSlot Slot; int CharacterNumber; int ShieldNumber; bool DefenceUpdateVisual; FP DefencePercentage }
    Synced event. Used when character's shield gets hit.
  • synced event BattleGiveUpStateChange {BattleTeamNumber Team; BattlePlayerSlot Slot; BattleGiveUpStateChange StateUpdate }
    Synced event. Used when player changes give up state.
  • synced event BattlePlayStateUpdate { bool IsInPlay; EntityRef ERef}
    Synced event. Used when PlayState is changed.
  • synced event BattleStoneCharacterPlayHitAnimation { BattleTeamNumber Team; BattleEmotionState Emotion }
    Synced event. Used to play StoneCharacter animations.
  • synced event BattleSpecialJoystickVisibilityChange { bool Show; BattlePlayerSlot Slot }
    Synced event. Used to change special joystick visibility.
  • synced event BattlePlayerClass100AimIndicatorUpdate { EntityRef ERef; bool Show; BattlePlayerSlot Slot; FPVector2 Direction; }
    Synced event. Used to update player class 100 aim indicator.
  • synced event BattleShieldChangeState { EntityRef ERef; BattleTeamNumber Team; bool ShieldAttached; int ShieldNumber }
    Synced event. Used when a shield is attached or detached.
  • synced event BattleCharacterDeath { BattlePlayerSlot Slot; int CharacterNumber; }
    Synced event. Used when a player gets hit when his defence is 0 or lower.

Debug events

  • synced event BattleDebugOnScreenMessage { QString<512> Message }
    Synced event. Used to display debug messages on screen.
