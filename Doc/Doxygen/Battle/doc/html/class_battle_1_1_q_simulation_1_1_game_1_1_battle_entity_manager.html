Detailed Description

BattleEntityManager handles Quantum entity management in the game.
Entities are registered, and can be retrieved and returned.

See {Entity Manager} for more info.

{Registered Entities} are stored offscreen when {OutOfPlay} and are assigned an {Entity ID} for accessing them.
Entities can be Retrieved using Get to be used in the arena. {InPlay}
Entities can be Returned using Return, teleporting them back offscreen. {OutOfPlay}

The BattleEntityManagerDataQSingleton struct is used internally to manage {Registered Entities}.
