Detailed Description

PlayerManager handles player management, allowing other classes to focus on gameplay logic.
Provides static methods to initialize, spawn, despawn, and query player-related data.

See {PlayerManager} for more info.
See {Player Overview} for more info.
See {Player Simulation Code Overview} for more info.

Handles initializing players that are present in the game, as well as spawning and despawning player characters.
The PlayerHandle and PlayerHandleInternal structs are used internally.

Player Index

Player Index is used internally to index player data arrays in BattlePlayerManagerDataQSingleton. Player {Slots} are mapped to the internal Player Indices using the PlayerHandleInternal Player Index Getter methods.
