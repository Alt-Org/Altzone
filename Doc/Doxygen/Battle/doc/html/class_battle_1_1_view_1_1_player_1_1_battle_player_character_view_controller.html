◆ AnimationState

enum Battle.View.Player.BattlePlayerCharacterViewController.AnimationState
private

Enum used to define player animation states.

Enumerator
Idle 

Player is idle, playing the idle breathing animation.
Condition: player is not moving.

Running 

Player is running, playing the running animation.
Condition: player is moving.

Stun 

Player is stunned, playing the stun animation.
Condition: player is stunned.
Blocking: blocks other states until in StunEnd state.

StunEnd 

Player is no longer stunned, transitioning to the next state.
Condition: player is no longer in Stun state.

◆ AnimationStep()

float Battle.View.Player.BattlePlayerCharacterViewController.AnimationStep ( float interval,
bool reset )
inlineprivate

Private helper method for playing looping animations.
Called every animation step.

Advances the _animationTimer and calculates the current normalized time of the looping animation based on interval, ranging from 0 to 1 and resetting to 0 after each completed cycle.

The animation loop can be force reset, which is recommended when changing animations.

Parameters
intervalThe interval in seconds of the current looping animation.
resetWhether to force reset the animation loop or not.
Returns
Normalized looped animation time.
