Detailed Description

PlayerShieldManager handles player shield management, allowing other classes to focus on gameplay logic.

See {ShieldManager} for more info. See {Player Overview} for more info. See {Player Simulation Code Overview} for more info.

Shield Index

Shield Index is used internally to index shield data arrays in BattlePlayerShieldManagerDataQSingleton. Each {Player Character Number} per player {Slot} is mapped to the internal Shield Index.
