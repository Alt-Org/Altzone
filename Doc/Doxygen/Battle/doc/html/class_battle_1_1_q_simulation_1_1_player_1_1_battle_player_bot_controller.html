Detailed Description

Handles the bot logic and implements helper methods for handling bots.

{Player Overview}
{Player Simulation Code Overview}

Bot AI is handled by generating input in GetBotInput that can be processed by the player like any other Input. Bot behavior and other spec settings are defined in BattlePlayerBotQSpec.

BotInputData Battle.QSimulation.Player.BattlePlayerBotController.GetBotInput ( Frame f,
BattlePlayerManager.PlayerHandle playerHandle )
inlinestatic

Handles bot AI logic and generates Quantum Input and/or Battle Command.

Bot behavior:

  • Selects a random character on random intervals or if none is selected.
  • Character movement: Moves intentionally or "misclicks" based on BattlePlayerBotQSpec.MissClickChance.
    • Intentional movement: Predicts and intercepts the projectile, with some inaccuracy based on BattlePlayerBotQSpec.Inaccuracy.
    • Misclick: Performs a random movement.
  • Gives up when teammate gives up.

Bot behavior spec settings is defined in BattlePlayerBotQSpec.

fCurrent simulation frame.
playerHandleThe player handle of the bot.
Returns
BotInputData struct, which contains the generated inputs.
